# สมุดบันทึกการสอน

เว็บสำหรับครู วิทยาลัยการอาชีพเขาย้อย ใช้ได้ทันทีบนเบราว์เซอร์ ไม่ต้องติดตั้ง

- **เช็คชื่อ** รายสัปดาห์ (สัปดาห์ที่ 1–18) พร้อมวันที่สอน: มา / สาย / ลา / ขาด
- **คะแนน** เก็บรายเดือน เดือนละ 4 ช่อง + ประมวลความรู้ พร้อมคำอธิบายหัวข้อคะแนน
- **จิตพิสัย** 16 รายการ (0–2) คำนวณคะแนนเต็ม 20
- **นักเรียนกลุ่มเสี่ยง** ตามเวลาเรียน คะแนนเก็บ งานค้าง ขาดติดต่อกัน และส่งรายงานทางอีเมล (Gmail)
- **บันทึกหลังการสอน** ดาวน์โหลด PDF ขนาด A4
- **ดาวน์โหลด Excel** หน้าปก + ใบเวลาเรียน/คะแนน (แบบ ESS) + จิตพิสัย + กลุ่มเสี่ยง (ฟอนต์ TH SarabunPSK)

## การเก็บข้อมูล
ข้อมูลนักเรียนและคะแนน **เก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งานเท่านั้น** ไม่ถูกส่งขึ้น GitHub หรือเซิร์ฟเวอร์ใด
ควรกด "ดาวน์โหลดไฟล์สำรอง" ในแท็บตั้งค่าเป็นประจำ และใช้ "กู้คืนจากไฟล์สำรอง" เมื่อย้ายเครื่อง

## ส่งอีเมลอัตโนมัติ
ดูขั้นตอนในแท็บ "ตั้งค่า" ของเว็บ (ใช้ Google Apps Script ในบัญชี Gmail ของคุณ) โครงโค้ดอยู่ที่ `apps-script/Code.gs`
