# สมุดบันทึกการสอน

เว็บสำหรับครู วิทยาลัยการอาชีพเขาย้อย ใช้ได้ทันทีบนเบราว์เซอร์ ไม่ต้องติดตั้ง

- **เข้าสู่ระบบ** ด้วยอีเมลและรหัสผ่าน (Supabase Auth) เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน
- **เลือกภาคเรียน/ปีการศึกษา** เพิ่มภาคเรียนใหม่และคัดลอกรายวิชา รายชื่อ หน่วยการสอนจากภาคเรียนเดิมได้

- **เช็คชื่อ** รายสัปดาห์ (สัปดาห์ที่ 1–18) พร้อมวันที่สอน: มา / สาย / ลา / ขาด
- **คะแนน** เก็บรายเดือน เดือนละ 4 ช่อง + ประมวลความรู้ พร้อมคำอธิบายหัวข้อคะแนน
- **จิตพิสัย** 16 รายการ (0–2) คำนวณคะแนนเต็ม 20
- **นักเรียนกลุ่มเสี่ยง** ตามเวลาเรียน คะแนนเก็บ งานค้าง ขาดติดต่อกัน และส่งรายงานทางอีเมล (Gmail)
- **บันทึกหลังการสอน** เลือกหน่วยการสอนและเรื่องที่สอนจากรายการ ดาวน์โหลด PDF ขนาด A4
- **ดาวน์โหลด Excel** หน้าปก + ใบเวลาเรียน/คะแนน (แบบ ESS) + จิตพิสัย + กลุ่มเสี่ยง (ฟอนต์ TH SarabunPSK)

## การเก็บข้อมูล
ข้อมูลของครูแต่ละคนเก็บในฐานข้อมูล Supabase (ตาราง `teacher_books` หนึ่งแถวต่อครูหนึ่งคน)
เปิด Row Level Security ไว้ ครูแต่ละคนอ่านและแก้ได้เฉพาะข้อมูลของตัวเอง
เว็บบันทึกขึ้นคลาวด์อัตโนมัติ และเก็บสำเนาไว้ในเบราว์เซอร์สำหรับใช้ตอนออฟไลน์
คีย์ที่อยู่ใน `index.html` เป็น publishable key ซึ่งเปิดเผยได้ตามปกติ

## ส่งอีเมลอัตโนมัติ
ดูขั้นตอนในแท็บ "ตั้งค่า" ของเว็บ (ใช้ Google Apps Script ในบัญชี Gmail ของคุณ) โครงโค้ดอยู่ที่ `apps-script/Code.gs`
